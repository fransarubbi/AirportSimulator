# Airport Simulation – Java & Maven  

## 📖 Description  
This project is implemented in **Java** and simulates the operation of an **airport**.  
The simulation uses the **bootstrapping method** and a **Future Event List (FEL)** to model system behavior.  

As a result, several **statistical measures** are computed to analyze and approximate real-world performance.  

## 💻 Software Details  
- **Language:** Java  
- **Build Tool:** Maven  
- **Testing:** Maven test framework implemented to validate statistical functions  
- **IDE/Editor:** Compatible with VS Code and other Java IDEs  

## 🚦 Features  
- Simulation of airport operations using an FEL-based approach  
- Statistical analysis of simulation outcomes  
- Implementation of bootstrapping for robust estimation  
- Unit tests with Maven to validate statistical functions  
- Automatic **graph generation** from tests to visualize statistical behaviors  
- Modular structure for maintainability and clarity  

## 📂 Project Structure  
- `/src` – Java source files (simulation logic, FEL, statistics)  
- `/target` – Compiled files and generated outputs  
- `pom.xml` – Maven configuration file (dependencies, build, test)  
- `.vscode` – Workspace settings for development  

## 🛠️ Usage  
1. Clone the repository.  
2. Open the project in your preferred Java IDE or VS Code.  
3. Build the project using Maven.
4. Execute tests and view statistical graphs.
5. Run the simulation.
